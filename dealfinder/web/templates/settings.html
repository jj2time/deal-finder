1. Free Rightmove reader

Reads Rightmove's ordinary search pages for each postcode search, slowly (a pause of a few seconds between pages), the way your browser would. It's free. It is against Rightmove's terms of use, and if Rightmove limits it, it stops and tells you; it never tries to get round that.

Optional: Apify scrapers (paid; also the only way to add Zoopla)

If you add a Rightmove scraper here, searches use it instead of the free reader. Leave both IDs empty to use the free reader.

  1. Create a free account at apify.com.
  2. Copy your API token from Settings → API & Integrations and paste it below.
  3. In the Apify Store, open a Rightmove scraper (and a Zoopla scraper if you want both) with good reviews that takes search result page URLs. Copy its ID from the page address, e.g. someone/rightmove-scraper.
Advanced: if your scraper's input is different

Deal Finder sends {"startUrls": [{"url": "…"}], "maxItems": 100} plus anything above. Check the scraper's Input tab for the names it expects.
